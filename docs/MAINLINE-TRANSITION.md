# AIOps 主线迁移范围

基于包含真实执行、审批、幂等、独立回读、恢复的后端 `16561b3`；前端基于 `9a7502c`，补入 9 月 19 日已部署的驻场员工能力工作台。旧发布分支、比赛材料、运行历史不改写。修改前原文件位于 `E:/SynapXnet/backups/mainline-transition-20261023/aiops`。

## 保留能力

全部原生运维菜单、三维总览、组织权限、驻场 Agent 聊天/任务/模型配置、知识和 Skill 能力工作台、跨域执行证据、审批绑定、委托鉴权、资源版本、幂等与补偿恢复。已有接口路径与内部 `com.synapxnet.goai` 包名是兼容契约，不按关键字删除。

## 退出默认产品的内容

- 移除比赛手机号白名单和固定验证码。验证码由企业短信网关实际发出，Redis 限流、过期和一次性消费；未配置网关时明确拒绝发送。
- 初始化 SQL 仅保留通用角色，不再创建比赛账号、团队、组织成员关系。存量线上数据库本轮不执行清理；导入旧数据库前需先备份并审核具体比赛实体。
- 登录页不再跳往固定 GOAI 域名，跨平台导航使用部署者配置的地址；无地址不产生链接。
- 固定容量/风控指标模拟不再作为默认真实证据；只有显式启用离线演练配置才可使用，真实运行时与治理能力继续可配置接入。
- README 使用主线安装和配置说明，不再默认引导比赛账号与访问码。

## 存量身份维护

`database/maintenance/archive-competition-identities.sql` 仅供独立备份后的人工维护，不随启动执行。默认预览、不修改业务记录。候选必须同时匹配旧种子 UID、用户名、手机号和原始密码摘要；已修改密码的真实账号不命中。确认后可显式启用归档、撤销候选账号会话和权限绑定、停用账号；已被其他成员使用的团队保留。账号主体、任务、审批、审计、资源、通用角色和租户/部门均不删除。归档冲突会阻止变更。

该脚本本轮未对存量数据库执行；本地没有可用 MySQL 实例，不将静态核对表结构等同于数据库执行验证。

## 证据来源

真实运行时继续接受已有独立演练来源 `REAL_CPU_SYNTHETIC_STAGING + synthetic=true`，并支持明确的生产来源 `PRODUCTION + synthetic=false`。未知来源、组合不一致、跨事件或跨工作空间结果拒绝显示为可信证据；生产来源不显示合成风控指标提示。来源标签仅描述服务报告的来源，不替代服务端资源隔离与授权校验。
